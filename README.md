# conditional-statement

This repository contains a Jupyter notebook with beginner exercises on Python conditional statements. Each example collects information from the user and uses nested `if` and `else` checks to decide what happens next.

## What’s inside

The notebook applies conditions to several everyday situations:

- **Loan eligibility:** checks country, employment, monthly salary, and credit score.
- **Admission eligibility:** checks state, marks, age, and qualification.
- **Online orders:** checks login, product availability, delivery location, and payment status.
- **ATM withdrawals:** checks card validity, PIN, account balance, and withdrawal status.
- **Insurance approval:** checks country, age, monthly income, and insurance criteria.
- **Promotion eligibility:** checks department, experience, performance, and salary criteria.

Together, these examples practice comparisons, combining user input with decision logic, and placing conditions inside other conditions. They also show how a program can respond differently when a requirement is met or not met.

## Run the notebook

Open [`conditional statement.ipynb`](conditional%20statement.ipynb) in Jupyter Notebook, JupyterLab, or Google Colab. Run the cells one at a time and enter the requested values when prompted. The examples are independent, so you can try different inputs to see how each decision changes.
